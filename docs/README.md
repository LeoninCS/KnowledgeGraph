# KnowledgeGraph 文档索引

KnowledgeGraph 是一个面向计算机基础知识学习者的纯前端可视化学习网站。项目首版以知识图谱总览为入口，以交互式知识模拟器为核心体验，先搭好可扩展框架，后续持续加入网络、操作系统、数据库、数据结构、计算机组成原理等知识内容。

- [项目设计文档](./specs/project-design.md)：定义技术选型、目录结构、数据模型、路由规划、部署方式和工程规范。

- [知识点文章优化进度](./kg-article-progress.md)：记录本轮文章级讲解已优化和未开始的知识点。
- [知识点可视化进度](./kg-visual-progress.md)：记录已可视化和未开始可视化的知识点。

## 首版目标

搭建一个适合长期扩展的纯前端项目框架：

1. 提供知识图谱总览页面。
2. 提供知识点详情页面。
3. 提供交互模拟器承载页。
4. 建立统一的知识数据模型。
5. 建立 GitHub Pages 静态部署流程。

## 推荐实现路线

1. 初始化 Vite + React + TypeScript 项目。
2. 建立 `src/data` 知识数据目录和 TypeScript 类型。
3. 搭建首页知识图谱、详情页、模拟器页三类页面。
4. 先实现 TCP 三次握手交互模拟器作为样板。
5. 配置 GitHub Actions，将构建产物发布到 GitHub Pages。
