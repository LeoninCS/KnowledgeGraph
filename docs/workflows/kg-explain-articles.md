# 文章知识点讲解续跑流程

## 目标

逐一完善文章中的所有知识点讲解，优先保证准确性、清晰度、引用质量和可续跑能力。

## 续跑标记

每完成一个知识点，在对应内容附近添加 HTML 注释标记：

```html
<!-- KG_EXPLAINED: 知识点名称 | yyyy-mm-dd | source_count=N -->
```

标记用于中断后续跑，用户界面中保持隐藏，AI 可识别。

## 工作流程

1. 通读文章，提取所有需要讲解的知识点，生成知识点清单。
2. 扫描文章中已有的处理标记：

   ```html
   <!-- KG_EXPLAINED: 知识点名称 | yyyy-mm-dd | source_count=N -->
   ```

   对已标记知识点保持原状，从剩余知识点继续处理。
3. 按复杂度与关联度分组：
   - 复杂、独立、容易误解的知识点逐个处理。
   - 简单且强相关的知识点以 2-4 个为一组处理。
   - 强关联概念保持术语统一，避免重复解释。
4. 每个知识点讲解前，使用 Chrome DevTools 在线检索资料。
5. 资料优先级：
   - 官方文档
   - 高质量中文资料
   - 权威英文资料
   - 高质量技术博客或工程实践文章
6. 基于资料补充讲解，内容要求清晰、易懂、精炼，帮助用户快速理解。
7. 每个知识点的讲解应覆盖：
   - 核心概念
   - 适用场景
   - 特殊场景
   - 边界情况
   - 常见误区
   - 实际使用注意点
8. 简单知识点保持短讲解；复杂知识点适当展开，以讲清楚为准。
9. 每个知识点讲解完成后，在侧边栏列出引用来源，包含来源标题和链接。
10. 中文来源优先，官方文档优先；引用数量以支撑准确讲解为准。
11. 每完成一个知识点，添加对应 `KG_EXPLAINED` 标记。
12. 全部完成后，检查文章整体风格、术语一致性、引用完整性和标记完整性。

## 质量标准

- 讲解准确，有可靠来源支撑。
- 表达精炼，优先讲清关键点。
- 复杂概念包含特殊场景和边界情况。
- 引用可追溯，标题和链接完整。
- 已处理知识点具备可续跑标记。
- 文章整体风格统一。

## 推荐 Goal 模板

```text
按 docs/workflows/kg-explain-articles.md 继续处理 docs/xxx.md，跳过已有 KG_EXPLAINED 标记，每次处理 3 个知识点。
```
