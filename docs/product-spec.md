# KnowledgeGraph Product Spec

## 产品说明

KnowledgeGraph 是一个面向所有计算机基础知识学习者的可视化学习网站。用户从知识图谱总览进入，选择知识点后查看结构化讲解、关系链路和交互式模拟器，通过主动操作理解抽象概念。首版采用纯前端静态站点，通过 GitHub Pages 发布。

## 目标用户

- 准备系统学习计算机基础的自学者。
- 正在学习计算机网络、操作系统、数据库、数据结构等课程的学生。
- 准备面试、需要查漏补缺的开发者。
- 想用可视化方式理解抽象概念的学习者。

## 核心价值

- 把分散的计算机基础知识组织成可浏览的知识图谱。
- 把抽象过程转成可操作模拟器，让用户通过操作理解状态变化。
- 用统一数据模型承载大量知识点，方便后续持续扩展。
- 以静态站点形式发布，维护成本低，访问路径简单。

## 首版功能需求

1. 展示知识图谱总览：以节点和连线展示知识分类、知识点和依赖关系。
2. 浏览知识点详情：展示概念摘要、前置知识、关联知识和后续学习建议。
3. 承载交互模拟器：提供统一页面容器，支持不同知识点挂载专属模拟器。
4. 操作 TCP 模拟样板：以三次握手为首个样板，用户点击发送报文，系统展示步骤反馈。
5. 管理知识数据：通过静态 TypeScript/JSON 数据维护知识点、关系、标签和页面配置。
6. 支持响应式访问：桌面端优先，兼顾平板和手机浏览。
7. 支持 GitHub Pages 发布：构建产物通过 Actions 自动发布。

## 页面规划

### 首页：知识图谱总览

整体采用三栏布局：

- 左侧导航栏：知识分类、搜索框、标签筛选。
- 中央图谱区：知识节点、关系连线、缩放控制、当前聚焦节点。
- 右侧信息栏：选中节点摘要、前置知识、关联知识、进入详情按钮。

桌面端比例建议为 `260px / 1fr / 320px`。移动端改为顶部分类切换、中央图谱、底部详情抽屉。

### 知识点详情页

页面采用上下结构：

- 顶部区域：知识点标题、难度、标签、学习时长、关联分类。
- 主内容区：概念说明、关键步骤、状态变化、常见误区。
- 右侧目录：本页锚点、前置知识、下一步学习。
- 模拟器入口：有模拟器的知识点显示“开始模拟”主按钮。

### 模拟器页

页面采用左右布局：

- 左侧模拟画布：展示客户端、服务端、报文流向和当前状态。
- 右侧操作面板：显示可选动作、当前任务、系统反馈、步骤历史。
- 底部时间线：展示完整流程进度、已完成步骤和待执行步骤。

TCP 三次握手样板的核心操作：

1. 用户选择客户端动作：发送 `SYN`。
2. 系统判断动作并更新客户端状态。
3. 用户选择服务端动作：发送 `SYN + ACK`。
4. 系统判断动作并更新服务端状态。
5. 用户选择客户端动作：发送 `ACK`。
6. 系统展示连接建立完成状态。

## 用户流程

### 快速学习流程

1. 用户打开首页，看到知识图谱总览。
2. 用户通过分类或搜索找到“TCP 三次握手”。
3. 用户点击节点，右侧信息栏展示摘要和前置知识。
4. 用户进入详情页，阅读概念和步骤。
5. 用户点击“开始模拟”，进入交互模拟器。
6. 用户按提示完成报文发送，系统实时反馈状态变化。
7. 用户完成模拟后回到图谱，继续学习关联知识点。

### 查漏补缺流程

1. 用户在首页搜索具体知识点。
2. 用户查看关联图谱，确认上下游知识。
3. 用户进入详情页查看关键解释。
4. 用户完成模拟器练习，验证理解程度。

## 数据字段需求

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 知识点唯一标识 |
| `title` | string | 知识点名称 |
| `category` | string | 所属分类 |
| `summary` | string | 一句话摘要 |
| `difficulty` | string | 入门、基础、进阶 |
| `tags` | string[] | 标签集合 |
| `prerequisites` | string[] | 前置知识点 ID |
| `related` | string[] | 关联知识点 ID |
| `simulator` | string | 模拟器类型 |
| `contentPath` | string | 详情内容路径 |

## 内容范围

首版建立框架和样板：

- 知识分类结构。
- 知识图谱页面。
- 知识点详情页面。
- 模拟器承载页面。
- TCP 三次握手交互模拟样板。

后续版本扩展方向：

- TCP 四次挥手。
- DNS 解析流程。
- HTTP 请求响应。
- 进程调度。
- 虚拟内存。
- B+ 树索引。
- 哈希表冲突处理。

## AI 能力规划

首版采用纯静态内容。后续可加入以下 AI 辅助能力：

- 根据知识点草稿生成结构化讲解。
- 根据知识点自动生成测验题。
- 根据用户学习路径推荐下一组知识点。
- 根据模拟过程错误生成针对性解释。

## 成功标准

- 用户能从首页找到知识点并进入详情页。
- 用户能在模拟器中完成 TCP 三次握手交互流程。
- 开发者能通过新增数据文件扩展知识点。
- 项目能通过 GitHub Pages 稳定发布。
